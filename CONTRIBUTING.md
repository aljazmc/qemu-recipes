# Contributing

Thanks for your interest in contributing to this project! Here is how you can help.

## Reporting Bugs

Before creating a new issue, please check the existing issues to make sure it hasn't already been reported. If it hasn't, open a new issue and include:
- A clear, descriptive title
- Steps to reproduce the bug
- Expected behavior vs. what actually happened
- Screenshots or error logs (if applicable)

## Suggesting Features

If you have an idea for a new feature or improvement, open an issue to discuss it first. Describe the problem you are trying to solve and how your idea would help.

## Submitting Pull Requests

1. **Fork** the repository and create a new branch from `main` (e.g., `git checkout -b fix/your-issue-name`).
2. **Make your changes** and keep them focused on a single bug or feature.
3. **Test your code** to make sure everything works and existing tests pass.
4. **Commit your changes** with a clear, descriptive message.
5. **Open a Pull Request** against the `main` branch and briefly explain what you changed and why.

## Code Style

Please follow the existing code style and formatting used in the repository. Update comments and documentation if you change how things work.
